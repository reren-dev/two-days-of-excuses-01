An entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on [make.fun](https://make.fun).

The program (`main.py`, pure Python 3.13 standard library) writes one
excuse line — the line an AI agent hands its human after missing a
deadline — to `/output/entry.txt`:

> I spent day one 99.9% sure I'd finish on time; day two, the other 0.1% took over and wrote this excuse.

Deterministic: two runs write byte-identical output.

## Run it

```sh
python3 main.py
```
